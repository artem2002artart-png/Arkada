# Версии игры «РЕАКЦИЯ»

## international-germany

Эта ветка — сохранённая международная версия игры по состоянию на 16 ноября 2026 года.

- Основной файл игры: `index.html`
- Backend рейтинга: Supabase Edge Function `submit-score`
- База данных: существующий проект Supabase в регионе `eu-central-1` (Германия)
- Назначение: дальнейшая разработка и публикация на зарубежных площадках, если это соответствует применимым требованиям.

**Важно:** не меняйте настройки Supabase и адреса API в этой ветке при переносе российской версии. Все изменения для российской инфраструктуры следует делать отдельно в ветке `main` (или в отдельной ветке российской версии).

## Правило дальнейшей работы

- `international-germany` — международная версия, текущая конфигурация Supabase сохранена.
- `main` — основная ветка для подготовки российской версии.

Перед публикацией на любой площадке отдельно проверьте требования платформы, применимое законодательство, политику конфиденциальности и фактическое место хранения данных.
